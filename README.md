# ThresholdSpikingRepetitionCount

This repository contains the implementation notebook for Threshold Spiking Repetition Counter (TSRC).
All experiments are implemented in a Kaggle notebook.

### 1. Import the Notebook

Download the `.ipynb` notebook from this repository and import it into Kaggle.

### 2. Add the Datasets

Add the following three Kaggle datasets to the notebook:

1. RecoFit: https://www.kaggle.com/datasets/michael42e34r23e/tsrc-recofit
2. CrossFit: https://www.kaggle.com/datasets/michael42e34r23e/tsrc-crossfit
3. CaRaCount: https://www.kaggle.com/datasets/michael42e34r23e/tsrc-caracount

The notebook automatically locates the attached datasets using their Kaggle input directories.

### 3. Run the Experiment

After attaching all three datasets, select **Run All** in Kaggle.

The notebook contains the complete pipeline used for the reported experiments, including dataset loading and preprocessing, model construction, training, cross-validation, and evaluation.
